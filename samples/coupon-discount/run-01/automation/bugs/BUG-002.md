# [API] 상품권만 담은 주문에서 할인 0원인 쿠폰이 자동 선택돼 결제 후 USED로 소진된다

- 심각도: **Major** (핵심 기능이 동작하지 않거나 우회가 어려운 결함)
- 우선순위: **P2** (핵심 기능 오류)
- 라인: 신규기능 · 기능: 쿠폰 / 제외 상품
- 재현율: 4/4 (2026-11-11 자동화 전체 실행 4회 모두 실패)
- 연결: TC TC-011 · 요구사항 REQ-02, REQ-04

## 환경
- 플랫폼: API
- 앱/빌드 버전: 샘플 쿠폰 QA 서버(개발문서 v0.3 기준)
- 서버 환경: QA 샘플 서버 http://127.0.0.1:8765
- 테스트 계정: 테스트마다 새로 생성(/test/members)
- 발생 시각: 2026-11-11 15:34

## 사전조건
- 로그인 회원
- 정률 10% 쿠폰, 정액 5,000원 쿠폰 각 1장 보유(AVAILABLE)
- 상품권(GIFT_CARD) 상품 50,000원(배송비 0원)

## 재현 절차
1. 상품권 50,000원만 장바구니에 담는다
2. 주문서에 들어간다
3. 쿠폰 영역을 확인한다
4. 결제를 완료한 뒤 보유 쿠폰 상태를 조회한다

## 기대 결과
- 쿠폰이 자동 선택되지 않고 적용할 수 없다
- 최종 결제 금액 50,000원
- 보유 쿠폰 2장 모두 AVAILABLE 유지

## 실제 결과
- 정률 10% 쿠폰 상태: 실제 USED (기대 AVAILABLE)
