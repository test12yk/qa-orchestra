# [API] 상품권이 섞인 장바구니에서 제외 상품 금액까지 최소 주문 금액에 포함돼 쿠폰이 적용된다

- 심각도: **Critical** (결제·금액 오류, 데이터 손실 등 출시를 막는 결함)
- 우선순위: **P1** (결제/금액 계산 오류로 이어지는 치명적 케이스)
- 라인: 신규기능 · 기능: 쿠폰 / 제외 상품
- 재현율: 4/4 (2026-11-11 자동화 전체 실행 4회 모두 실패)
- 연결: TC TC-009 · 요구사항 REQ-02, REQ-01

## 환경
- 플랫폼: API
- 앱/빌드 버전: 샘플 쿠폰 QA 서버(개발문서 v0.3 기준)
- 서버 환경: QA 샘플 서버 http://127.0.0.1:8765
- 테스트 계정: 테스트마다 새로 생성(/test/members)
- 발생 시각: 2026-11-11 15:34

## 사전조건
- 로그인 회원
- 정액 5,000원 쿠폰 1장 보유
- 일반 상품 26,999원(배송비 3,000원), 상품권 상품 10,000원

## 재현 절차
1. 일반 상품 26,999원과 상품권 10,000원을 장바구니에 담는다
2. 주문서에 들어간다
3. 쿠폰 영역을 확인한다
4. API로 POST /orders/{orderId}/coupon 을 호출한다

## 기대 결과
- 쿠폰을 적용할 수 없다(최소 주문 금액 판정 기준 29,999원 = 26,999 + 3,000)
- 쿠폰 할인 0원, 최종 결제 금액 39,999원(26,999 + 3,000 + 10,000)

## 실제 결과
- 쿠폰 적용 응답: 실제 200 성공 (기대 거부(판정 기준 29,999원))
- 쿠폰 할인: 실제 5,000원 (기대 0원)
- 최종 결제 금액: 실제 34,999원 (기대 39,999원)
