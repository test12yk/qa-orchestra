# 장바구니 쿠폰 할인 실행 전 TC 검토

**실행 시작 가능** — TC 작성가 담당 지적 4건 중 3건이 TC v2(66개)로 해결됐고 1건은 Q8 답 대기 — 실행을 시작해도 됨

- 새 TC 3개(TC-064~066)는 기대 결과 계산과 근거를 확인함. 이미 실행한 TC는 바뀌지 않아 다시 실행할 TC 없음
- 새 TC를 쓰면서 문서에 없는 규칙 2가지(취소 시 포인트 반환, 자동 선택·정렬의 할인액 기준)가 드러나 기획 분석가에게 질문 추가를 요청함

## 검토 후 지적에서 뺀 자동 점검 후보
- REQ_NO_BOUNDARY (REQ-03): 숫자는 '1장'·오류 코드 409일 뿐 범위 조건이 아님. 2장째 적용 거부는 TC-014~016이 확인
- REQ_NO_BOUNDARY (REQ-05): 10%·5,000원은 쿠폰 종류 예시라 경계 조건이 아님. 한도·최소 결제액 경계는 REQ-06·08 TC가 확인
- RISK_NO_TC (쿠폰 동시 사용): 낱말이 달라 자동 연결만 안 됐을 뿐 TC-043(동시 결제)·TC-044(다른 주문에서 먼저 USED)가 위험 설명(승인 전 틈, 409는 같은 주문만 막음)을 그대로 확인
- PRIORITY_INFLATED (P1): 팀 기준(P1 = 결제·금액 계산 오류)대로 매겨졌고, 이 기능이 금액 계산 위주라 비율이 높음. 기준 위반 없음
