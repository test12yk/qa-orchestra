# 장바구니 쿠폰 할인 실행 결과 검토

**보완 후 판정** — 자동화 54개는 끝났지만 수동 8개와 blocked 1개(P1 회귀)가 아직 실행되지 않아 보완 후 판정을 권함

- Fail 3건(QAO-8·10·11)이 모두 미확정 질문(Q5·Q4)에 기댄 판정이라, 답에 따라 결함이 아닐 수 있음 — 판정관은 먼저 Q4·Q5 답을 확인할 것
- Pass 46개 중 23개가 임시 가정 기준 — 질문 답이 가정과 다르면 해당 TC만 다시 판정
- 결함·보류가 몰린 곳: 제외 상품 최소 금액(REQ-02, Fail 2/3)과 취소 시 쿠폰 복구(REQ-16·17) — 영향 기능은 결제 금액 계산·주문 취소
