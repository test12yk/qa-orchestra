8테스트 범위 · 준비 사항

이번에 테스트하는 것

  • REQ-01 ~ REQ-18 전체
  • 취소·환불 연계(전체·부분 취소)
  • 쿠폰 동시 사용
  • 포인트 병행 사용

이번에 테스트하지 않는 것

  • 첫 구매 쿠폰 최소 금액 1만 원 인하 — 슬랙 11/06 박기획(PM): 이번 스프린트 범위 아님, 다음 차수 검토
  • 판매자 정산 금액 상세 검증 — 정책상 영향 없음, 구현 문서 없음. 정산 금액 불변 확인만 회귀로 수행

테스트 계정

  • 쿠폰 여러 장(정률·정액) 보유 회원
  • 쿠폰 + 포인트 보유 회원
  • 쿠폰 없는 회원

쿠폰 데이터

  • 정률 10% 쿠폰(maxDiscount 10,000원 / 10,000원 초과 설정값)
  • 정액 5,000원 쿠폰
  • 할인액이 같은 쿠폰 2장
  • 만료 D-3·D-2·D-1·D-0 쿠폰
  • 취소 시점 직전에 만료되는 쿠폰

상품·장바구니

  • 배송비 유료 상품(예: 상품 27,000원 + 배송비 3,000원 경계)
  • 상품 29,999원 / 30,000원 경계
  • 상품권·e쿠폰 카테고리 상품 + 일반 상품 혼합
  • 정률 한도 경계(예: 100,000원 이상 상품)
  • 결제 금액이 100원 근처가 되는 저가 상품

환경·도구

  • 테스트 PG(승인 성공·실패·지연 재현)
  • 동시 요청 도구(같은 쿠폰 두 주문 동시 결제)
  • API 직접 호출 도구(409 확인)
  • 쿠폰 상태 조회 권한(DB 또는 관리자)
