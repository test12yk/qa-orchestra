# [Web] 상품권이 섞인 장바구니에서 제외 상품 금액까지 최소 주문 금액에 포함돼 쿠폰이 적용된다

- 심각도: **Critical** (결제·금액 오류, 데이터 손실 등 출시를 막는 결함)
- 우선순위: **P1** (결제/금액 계산 오류로 이어지는 치명적 케이스)
- 라인: 신규기능 · 기능: 쿠폰 / 제외 상품
- 재현율: 3/3
- 연결: TC TC-009 · 요구사항 REQ-01, REQ-02

## 환경
- 플랫폼: Web
- 앱/빌드 버전: web 2026.11.10-rc1
- 브라우저: Chrome 131
- 서버 환경: QA(stage)
- 테스트 계정: qa_coupon_01
- 발생 시각: 2026-11-11 13:30

## 사전조건
- 로그인 회원
- 정액 5,000원 쿠폰 1장 보유
- 일반 상품 26,999원(배송비 3,000원), 상품권 상품 10,000원

## 재현 절차
1. 일반 상품 26,999원과 상품권 10,000원을 장바구니에 담는다
2. 주문서에 들어간다
3. 쿠폰 영역을 확인한다
4. API로 POST /orders/{orderId}/coupon 을 호출한다

## 기대 결과
- 쿠폰을 적용할 수 없다(최소 주문 금액 판정 기준 29,999원 = 26,999 + 3,000)
- 쿠폰 할인 0원, 최종 결제 금액 39,999원(26,999 + 3,000 + 10,000)

## 실제 결과
- 쿠폰이 자동 선택되고 -5,000원 할인된다
- 최종 결제 금액 34,999원
