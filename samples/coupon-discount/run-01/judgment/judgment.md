# 장바구니 쿠폰 할인 신규 기능 판정

**판정관 추천: 편입 보류** — 릴리즈 불가 이슈 3개(Critical 결함 QAO-8, P1 TC 미실행 1개·판정 보류 3개)가 남아 지금은 편입 보류 — 대부분은 기획 답(Q4·Q5 등)을 받으면 해결된다

- E2 결함: Critical QAO-8(제외 상품이 최소 주문 금액에 포함) 미해결
- E1·E3: P1 TC-059(부분 취소 회귀) 미실행, P1 TC-022·027·048 판정 보류 — 금액·환불 계산이 확인되지 않음
- E6 고위험 영역: '최소 주문 금액'과 '취소 시 쿠폰 복구'에 Fail
- E4: 위 Fail 3건이 모두 Q4·Q5 임시 가정 기준이라, 답이 'API 동작이 맞다'면 버그가 닫히고 조건부 편입으로 바로 바뀔 수 있음
- E8 기존 기능은 Fail 없음 — 편입이 기존 결제·취소를 깨뜨린 근거는 없음

**사람의 결정:** 아직 결정 전

## 릴리즈 이슈 → 해결할 일

- **[릴리즈 불가] B-01 Critical 결함 QAO-8 미해결 — 제외 상품(상품권)까지 최소 주문 금액에 포함돼 쿠폰이 적용됨. 고위험 '최소 주문 금액'의 Fail이며, 결함인지는 Q5 답에 달림**
  - K-01 Q5(제외 상품을 최소 주문 금액에서 빼는지) 답 확정 (기획·정책 담당(답변)) — 확인: 답에 맞춰 TC-009·010·011 기대 결과를 고정하고 다시 판정 — 결함이 아니면 QAO-8·10 닫기
  - K-03 K-01 뒤에도 결함이면 QAO-8 수정 (개발(수정)) — 확인: 수정 빌드에서 TC-009·010 Pass, QAO-8 완료

- **[릴리즈 불가] B-02 P1 회귀 TC-059(쿠폰 없는 부분 취소) 미실행 — 기존 부분 취소 환불이 그대로인지 모름**
  - K-05 P1 회귀 TC-059(쿠폰 없는 부분 취소) 실행 (신규 기능 자동화) — 확인: 변경 전 배송비 환불 기준값을 받아 실행해 Pass

- **[릴리즈 불가] B-03 P1 TC 3개 판정 보류 — 정률 한도(TC-022)·100원 미만 결제(TC-027)·부분 취소 안분(TC-048) 금액이 확인되지 않음**
  - K-02 Q4(전체·부분 취소와 만료 쿠폰 복구 규칙) 답 확정 (기획·정책 담당(답변)) — 확인: TC-045~050 다시 판정 — 결함이 아니면 QAO-11 닫기
  - K-06 Q2·Q7·Q8 답으로 P1 판정 보류 TC-022·027·048 판정 (기획·정책 담당(답변)) — 확인: 답 받은 뒤 기대 결과 고정·재실행해 Pass

- **[조건부 릴리즈] B-04 Major 결함 QAO-10 미해결 — 상품권만 담은 주문에서 할인 0원 쿠폰이 소진됨. 결함인지는 Q5 답에 달림**
  - K-01 Q5(제외 상품을 최소 주문 금액에서 빼는지) 답 확정 (기획·정책 담당(답변)) — 확인: 답에 맞춰 TC-009·010·011 기대 결과를 고정하고 다시 판정 — 결함이 아니면 QAO-8·10 닫기
  - K-04 K-01·02 뒤에도 결함인 Major(QAO-10·11)는 수정하거나, 다음 버전으로 미루는 것을 QA 매니저가 결정 (QA 매니저(결정)) — 확인: 수정 시 TC-011·050 Pass / 미루면 판정서에 결정·이유 기록

- **[조건부 릴리즈] B-05 Major 결함 QAO-11 미해결 — 만료 쿠폰이 전체 취소로 복구됨(고위험 '취소 시 쿠폰 복구'의 Fail). 결함인지는 Q4 답에 달림**
  - K-02 Q4(전체·부분 취소와 만료 쿠폰 복구 규칙) 답 확정 (기획·정책 담당(답변)) — 확인: TC-045~050 다시 판정 — 결함이 아니면 QAO-11 닫기
  - K-04 K-01·02 뒤에도 결함인 Major(QAO-10·11)는 수정하거나, 다음 버전으로 미루는 것을 QA 매니저가 결정 (QA 매니저(결정)) — 확인: 수정 시 TC-011·050 Pass / 미루면 판정서에 결정·이유 기록

- **[조건부 릴리즈] B-06 수동 TC 8개 미실행 — 제외 안내 문구·최대 할인 라벨·결제 요약 화면·상품권 발급·정산 금액**
  - K-07 수동 TC 8개 실행(제외 안내 문구·최대 할인 라벨·결제 요약 화면·상품권 발급·정산 금액) (수동 테스트 담당) — 확인: 결과 시트에 Pass/Fail 기록, Fail이면 버그 등록

- **[조건부 릴리즈] B-07 P2·P3 TC 2개 판정 보류 — 동률 쿠폰 자동 선택·라벨(TC-031·032)**
  - K-08 Q10(동률 쿠폰 자동 선택 기준·라벨) 답으로 TC-031·032 판정 (기획·정책 담당(답변)) — 확인: 답 받은 뒤 기대 결과 고정·재실행해 Pass
