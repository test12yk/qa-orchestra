# 2026.12 정기 릴리즈(샘플) 회귀 범위

26개 중 17개 실행 — 필수 8 · 직접 영향 5 · 간접 영향 4 · 이번엔 제외 9

## 필수 (8)

- RG-0001 가입한 이메일·비밀번호로 로그인하면 메인 화면으로 이동한다 (P1) — P1은 매 릴리즈 실행
- RG-0008 결제 금액은 상품 금액 합계에 배송비를 더한 값이다 (P1) — P1은 매 릴리즈 실행 · 영향: 결제 금액 계산
- RG-0010 포인트 3,000P를 쓰면 결제 금액이 3,000원 줄고 잔액도 줄어든다 (P1) — P1은 매 릴리즈 실행 · 영향: 포인트 사용(차감 순서·금액)
- RG-0014 카드 결제 승인 금액은 주문서 최종 결제 금액과 같다 (P1) — P1은 매 릴리즈 실행 · 영향: PG 결제 승인
- RG-0015 PG 승인이 실패하면 주문이 만들어지지 않고 포인트도 차감되지 않는다 (P1) — P1은 매 릴리즈 실행 · 영향: PG 결제 승인
- RG-0017 결제 완료 주문을 전체 취소하면 결제 금액 전액이 환불된다 (P1) — P1은 매 릴리즈 실행 · 영향: 주문 전체 취소
- RG-0018 포인트를 쓴 주문을 전체 취소하면 쓴 포인트가 되돌아온다 (P1) — P1은 매 릴리즈 실행 · 영향: 주문 전체 취소
- RG-0019 상품 2개 중 1개를 부분 취소하면 그 상품 금액만 환불된다 (P1) — P1은 매 릴리즈 실행 · 영향: 주문 부분 취소

## 직접 영향 (5)

- RG-0009 여러 판매자 상품을 함께 주문하면 판매자별 배송비가 각각 더해진다 (P2) — 직접 영향: 결제 금액 계산
- RG-0011 보유 포인트보다 많이 입력하면 보유 포인트까지만 쓰인다 (P2) — 직접 영향: 포인트 사용(차감 순서·금액)
- RG-0012 주문서 결제 금액 요약에 상품 금액·배송비·포인트·최종 금액이 순서대로 보인다 (P3) — 직접 영향: 주문서 결제 금액 요약 화면
- RG-0020 부분 취소로 무료배송 기준 아래가 되면 배송비 3,000원을 빼고 환불한다 (P2) — 직접 영향: 환불 금액 계산
- RG-0022 같은 쿠폰은 한 번만 받을 수 있다 (P2) — 직접 영향: 쿠폰 상태 관리(AVAILABLE/USED)

## 간접 영향 (4)

- RG-0013 30,000원 이상 주문하면 기본 배송비 3,000원이 무료가 된다 (P2) — 간접 영향: 배송비 계산
- RG-0016 상품권 50,000원을 단독 주문하면 결제 후 상품권 번호가 발급된다 (P2) — 간접 영향: 상품권·e쿠폰 카테고리 상품 주문
- RG-0021 이벤트 페이지에서 쿠폰을 받으면 쿠폰함에 AVAILABLE로 들어온다 (P2) — 쿠폰 할인은 발급받은 쿠폰을 쓰므로 발급 → 쿠폰함 흐름을 한 번 확인(발급 코드는 안 바뀜)
- RG-0025 판매자 정산 기준 금액은 상품 판매 금액에서 수수료를 뺀 값이다 (P2) — 간접 영향: 판매자 정산 금액

## 이번엔 제외 (9)

- RG-0002 비밀번호를 5번 틀리면 계정이 10분간 잠긴다 (P2) — 이번 릴리즈 변경과 관련 없음
- RG-0003 필수 약관에 동의하고 이메일 인증을 마치면 가입된다 (P2) — 이번 릴리즈 변경과 관련 없음
- RG-0004 상품명으로 검색하면 이름이 맞는 상품이 결과에 나온다 (P2) — 이번 릴리즈 변경과 관련 없음
- RG-0005 품절 상품 상세에서는 구매 버튼이 비활성이다 (P3) — 이번 릴리즈 변경과 관련 없음
- RG-0006 상품을 담으면 장바구니 수량과 금액이 바로 바뀐다 (P2) — 이번 릴리즈 변경과 관련 없음
- RG-0007 재고보다 많이 담으면 재고 수량까지만 담긴다 (P3) — 이번 릴리즈 변경과 관련 없음
- RG-0023 쿠폰함에 쿠폰 유효기간이 날짜로 보인다 (P3) — 간접 영향(쿠폰 유효기간·만료 처리)이지만 P3 — 간접 영향은 P1·P2만 실행
- RG-0024 배송 중 주문은 주문 상세에서 송장 번호와 배송 단계가 보인다 (P2) — 이번 릴리즈 변경과 관련 없음
- RG-0026 구매 확정한 주문에만 리뷰를 쓸 수 있다 (P3) — 이번 릴리즈 변경과 관련 없음
