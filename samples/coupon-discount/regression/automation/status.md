# 회귀 자동화 현황

스위트 커머스 회귀 스위트(샘플) v2 API 케이스 8개 (이번 범위) — 실행 가능 8

## 실행 가능 (8)

- RG-0008 결제 금액은 상품 금액 합계에 배송비를 더한 값이다 — 직접 작성
- RG-0010 포인트 3,000P를 쓰면 결제 금액이 3,000원 줄고 잔액도 줄어든다 — 직접 작성
- RG-0011 보유 포인트보다 많이 입력하면 보유 포인트까지만 쓰인다 — 직접 작성
- RG-0014 카드 결제 승인 금액은 주문서 최종 결제 금액과 같다 — 직접 작성
- RG-0017 결제 완료 주문을 전체 취소하면 결제 금액 전액이 환불된다 — 직접 작성
- RG-0018 포인트를 쓴 주문을 전체 취소하면 쓴 포인트가 되돌아온다 — 직접 작성
- RG-0019 상품 2개 중 1개를 부분 취소하면 그 상품 금액만 환불된다 — 직접 작성
- RG-0020 부분 취소로 무료배송 기준 아래가 되면 배송비 3,000원을 빼고 환불한다 — 직접 작성
