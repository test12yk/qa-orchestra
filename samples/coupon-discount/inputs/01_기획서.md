# [기획서] 장바구니 쿠폰 할인 v1.0
작성: 커머스기획팀 / 2026-10-28

## 1. 배경
첫 구매 전환율 개선을 위해 주문서에서 보유 쿠폰을 사용할 수 있게 한다.

## 2. 쿠폰 사용 조건 (p.3)
- 상품 금액 합계 **30,000원 이상**(배송비 제외)일 때 사용 가능
- 주문 1건당 쿠폰 **1장**만 사용 가능

## 3. 할인 방식 (p.4)
- 정률 쿠폰(예: 10%), 정액 쿠폰(예: 5,000원) 두 종류
- 주문서 진입 시 **할인 금액이 가장 큰 쿠폰을 자동 선택**, 사용자가 변경 가능

## 4. 결제 금액 계산 (p.5)
- 할인 적용 순서: **쿠폰 할인 → 포인트 사용**

## 5. 주문 취소 (p.6)
- 주문 취소 시 사용한 쿠폰은 **즉시 복구**된다.
